# Слесарь ЦТП

2D-симулятор жизни слесаря центрального теплового пункта для Android (горизонтальный режим, на русском).

Ты — Коля Палкин, слесарь 3-го разряда. В твоём ведении ЦТП-7 и квартал из пяти домов.
Из ЦТП уходят четыре трубы: **Т1/Т2** — отопление (подача/обратка), **Т3/Т4** — горячая вода (подача/циркуляция).
Задача — продержаться отопительный сезон до 15 мая и не лишиться доверия начальства.

## Установка

Скачать [`dist/SlesarSim.apk`](dist/SlesarSim.apk) на телефон и установить (разрешить установку из неизвестных источников).
Android 5.0+.

## Что есть в игре

- **ЦТП**: теплообменники отопления и ГВС, пары насосов (рабочий/резервный), 8 задвижек, грязевик, подпитка, дренажи,
  манометры, шкаф управления с погодным регулятором.
- **Гидравлика**: давление, расход, температура по графику от погоды, температура сети ТЭЦ, утечки, завоздушивание,
  сухой ход, работа на закрытую задвижку, перепрессовка при забытой подпитке.
- **Ремонты**: замена задвижек (мини-игра — открутить болты и затянуть крест-накрест), перенабивка и подтяжка сальника,
  закисшие задвижки, замена подшипников и торцевых уплотнений (техкарта — по порядку, иначе удар током), чистка грязевика,
  промывка теплообменников.
- **Квартал**: температура в квартирах и горячей воды в каждом доме, жалобы жильцов, подвалы домов (воздух, хомуты,
  показания теплосчётчиков), порывы теплотрассы, отключения света и воды, похолодания и оттепели.
- **Жизнь**: бодрость, сытость, здоровье, настроение; квартира (сон, еда, душ от своего же ЦТП, телевизор),
  магазин, зарплата 5-го и 20-го, премии, шабашки, разряды, обход и журнал, проверки начальника, склад запчастей.

## Устройство

Игра — HTML5 Canvas + JS (`web/`) в WebView-обёртке (`android/`), без внешних библиотек и ассетов: вся графика рисуется кодом.

```
web/js/sim.js        физика контуров, домов, износ
web/js/events.js     события, заявки, сообщения, календарь
web/js/actions.js    действия героя
web/js/minigames.js  болты и техкарты
web/js/render.js     отрисовка сцен
web/js/ui.js         HUD, панели, телефон, меню
```

## Сборка

Нужны Android SDK (build-tools 34, platform android-34) в `/opt/android` (или `ANDROID_HOME`) и JDK 17+:

```
./build.sh            # → dist/SlesarSim.apk
```

Ключ подписи `android/slesarsim.keystore` (пароль `android`) — открытый тестовый, не для магазина.

## Проверки

```
python3 tools/scenarios.py out/   # скриншоты всех сцен + 30 дней симуляции без ошибок JS
python3 tools/balance.py 226      # «идеальный слесарь»-бот проходит весь сезон
```

В браузере игру можно открыть напрямую: `web/index.html`.
